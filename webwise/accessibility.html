Accessibility & Inclusive Design

Web accessibility means designing websites so people with different abilities can access and use the content.

Accessibility Techniques

  • Provide alt text for images.
  • Use strong color contrast.
  • Support keyboard navigation.
  • Use clear headings and simple language.
  • Provide captions and transcripts for media.
  • Use visible labels on form fields.

Inclusive Design

Inclusive design considers differences in ability, age, background, device, and experience. A website should not assume that every user interacts with content in the same way.

Accessibility on WebWise

WebWise includes keyboard-friendly navigation, clear headings, text-size controls, a high-contrast option, and a consistent layout. The website will also be tested with the WAVE accessibility tool.
